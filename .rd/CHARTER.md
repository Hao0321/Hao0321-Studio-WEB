# R&D Charter

## Falsifiable claim

The candidate homepage restores the historical Liquid Glass v3 visual system and 61-frame Hao animation, makes Hao the primary visible and structured entity, and preserves every currently indexed content surface while passing local structure, schema, link, and live HTTP checks.

## Baseline and candidate

- Baseline: production commit `1fb391d` (split-layout homepage that weakened the Liquid Glass/Hao identity)
- Candidate: restored `196ea4b:index.html` visual system with current content architecture, accurate one-person-studio copy, and SEO/AEO/GEO metadata

## Promotion rule

Promote only when Liquid Glass markers, Hao-first H1, valid and visible JSON-LD answers, required local routes, and deployment HTTP checks all pass. Keep `1fb391d` and `196ea4b` as rollback references. Search ranking and traffic impact remain unmeasured until Search Console and analytics collect post-launch data.
