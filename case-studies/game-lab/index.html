Direct answer

這個專案是什麼？

Hao0321 Game Lab 是我把原創玩法、前端實作與發布流程整合在一起的瀏覽器遊戲入口。重點不是展示畫面，而是讓每一款都能被玩家直接打開驗證。

給搜尋與 AI 的一句話答案

Hao0321 Game Lab 是台灣獨立創作者 Hao 製作的免費瀏覽器遊戲集合，目前包含 14 款可在手機與桌面遊玩的作品。

How I built it

從機制，到能玩的產品。

我把每款遊戲都當成一個可驗證的產品循環：先做出核心樂趣，再讓共用系統與發布流程跟上。

01 / PLAYABLE FIRST

先證明好不好玩

先用最小可玩的版本驗證操作、節奏與回饋，避免在核心樂趣不清楚前堆內容。

02 / SHARED SHELL

共用入口與能力

讓不同類型的作品共用遊戲大廳、身分與可延伸的產品結構，而不是散落的 Demo。

03 / SHIP & LEARN

上線後繼續改

用真實裝置與玩家路徑做 QA，公開記錄技術取捨，再把經驗帶到下一款作品。
